♟ Blindfold Chess

Move mode (default)
Type 3 keys: piece · file · rank
Pieces
s=king d=rook f=pawn
j=knight k=bishop l=queen
Files
a=a s=b d=c f=d
j=e k=f l=g ;=h
Ranks
a=1 s=2 d=3 f=4
j=5 k=6 l=7 ;=8
Castling
Kingside (white): sla → king to g1
Queenside (white): sda → king to c1
(Black mirrors: g8/c8)
Ambiguous moves
If two pieces can reach the same square, you'll hear "ambiguous".
Press a 4th key for the source file or rank to disambiguate.
Example: Ra1→d1 vs Rh1→d1 → type sfda (rook d1, from file a)
Puzzle replay
g → previous move   h → next move
Draw mode — press m to toggle
2 keys (file+rank) → highlight square
4 keys (file+rank+file+rank) → draw arrow
c → clear all drawings (works in any mode)
Settings

Extension activates automatically when a chess.com game board is detected. Opponent moves are announced aloud. Your moves are confirmed on key entry.
